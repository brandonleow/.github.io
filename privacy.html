Privacy Policy

Life Dashboard · Last updated 19 October 2026

Who uses this app

Life Dashboard is a personal tool used only by its owner. It is not offered to the public.

What data it accesses

With the owner's permission, the app reads (read-only):

  • Google Calendar events, to show today's schedule and upcoming deadlines.
  • Gmail message details (sender, subject, short preview), to list important emails.

The app cannot send, change or delete any emails or calendar events.

How the data is stored

Data is stored only on the owner's own computer. It is not sold, shared or sent to any third party, and it is not used for advertising.

Google API Services

Life Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's files from the computer removes all stored data.
